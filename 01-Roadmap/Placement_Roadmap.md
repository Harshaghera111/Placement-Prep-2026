#### ✅ Arrays
- Prefix Sum, Kadane's Algorithm
- Sliding Window (Fixed & Variable)
- Two Pointers
- Dutch National Flag
- Sorting (Merge Sort, Quick Sort)

#### ✅ Strings
- Reversal, Palindrome Check
- Anagram Detection
- KMP / Z-Algorithm (optional)
- String compression
- Sliding Window on Strings

#### ✅ HashMap
- Frequency Maps
- Group Anagrams
- Two Sum variants
- Subarray with given sum
- First non-repeating element

#### ✅ Stack
- Valid Parentheses
- Monotonic Stack (NGE, Stock Span)
- Min Stack
- Evaluate Expression

#### ✅ Queue & Deque
- Circular Queue
- Sliding Window Maximum
- Level Order Traversal (intro)

#### ✅ Binary Search
- Classic Binary Search
- Search in Rotated Array
- Find Peak Element
- Binary Search on Answer (Capacity to Ship, etc.)

# 📄 Resume Notes & Tips

> Your resume is your first impression. Make every word count. ATS-friendly + human-readable = ideal.

---

## 📋 Resume Sections (Optimal Order)

```
1. Header (Name, Contact, LinkedIn, GitHub)
2. Summary (2–3 lines, optional but impactful for experienced)
3. Education
4. Skills
5. Projects (most important for freshers!)
6. Experience (Internships, Part-time)
7. Achievements & Certifications (optional)
```

---

## ✅ Resume Quality Checklist

### Format
- [ ] 1 page max (for freshers/internship)
- [ ] Clean font: Calibri, Arial, or Garamond (10–12pt)
- [ ] Consistent formatting: same bullet style, date format
- [ ] PDF format (not Word) when submitting
- [ ] No tables, headers/footers, or columns (break ATS)
- [ ] Save as: `Harsh_Resume_2026.pdf`

### Content
- [ ] Contact: Email (professional), Phone, LinkedIn, GitHub
- [ ] Each bullet starts with a strong action verb
- [ ] Every bullet includes quantified impact where possible
- [ ] No spelling errors — proofread 3 times
- [ ] No "References available upon request" (waste of space)
- [ ] Skills section matches the JD keywords

### ATS Optimization
- [ ] Use exact keywords from the job description
- [ ] Avoid graphics, icons, and images
- [ ] Use standard section headers (not "My Work" — use "Projects")
- [ ] Don't put info in text boxes or tables

## 🔑 Action Verb Bank

**Built/Developed:** Built, Developed, Engineered, Implemented, Designed, Architected

**Improved:** Optimized, Reduced, Improved, Increased, Accelerated, Enhanced

**Led:** Led, Managed, Coordinated, Directed, Organized, Mentored

**Analyzed:** Analyzed, Evaluated, Investigated, Diagnosed, Profiled

**Delivered:** Shipped, Deployed, Launched, Released, Delivered

---

## 💡 How to Write Bullet Points (STAR in one line)

**Formula: [Action Verb] + [What] + [How] + [Impact]**

**❌ Bad:**
> "Worked on the backend of GramSathi"

**✅ Good:**
> "Engineered a Node.js REST API serving 5+ endpoints for farmer profile management, scheme eligibility, and OTP authentication, reducing average response time to under 200ms"

**❌ Bad:**
> "Used React and made a nice UI"

**✅ Good:**
> "Built a multilingual PWA using React.js with Service Workers and IndexedDB, enabling offline functionality for rural users with unreliable connectivity"

## 📝 Project Section Template

**Format:**
```
Project Name | Tech Stack | [GitHub] [Live]
• Bullet 1: What you built and its purpose
• Bullet 2: Key technical implementation detail
• Bullet 3: Quantified impact or challenge solved
```

**GramSathi Example:**
```
GramSathi — Rural Tech Platform | Node.js, React, MongoDB, LangChain | [GitHub]
• Built a multilingual (Hindi/English) full-stack platform connecting 100+ farmers
  with government scheme eligibility checks and AI-powered farming advice
• Implemented a RAG pipeline using LangChain + ChromaDB that retrieves relevant
  agricultural context and generates grounded answers via GPT-4o
• Engineered offline-first PWA using Service Workers + IndexedDB, achieving
  Lighthouse performance score of 91 in low-bandwidth conditions
```

## 🎯 Target Company-Specific Tips

### Product Companies (Flipkart, CRED, Zepto)
- Emphasize scale: "Designed for X users", "handles Y requests/sec"
- Show product thinking: mention user impact, not just tech
- Include metrics wherever possible

### Startups
- Emphasize ownership: "Sole developer", "Led end-to-end"
- Show breadth: full-stack, DevOps, product thinking
- Highlight speed: "Shipped MVP in 3 weeks"

### AI Companies (AI-first startups, OpenAI partners)
- Lead with AI Engineering skills
- Mention specific frameworks: LangChain, RAG, vector DBs
- Show hands-on projects with LLMs

## 📋 LinkedIn Optimization

- **Headline:** `Final Year CS Student | Full Stack + AI Engineering | Seeking SDE/AI Roles 2026`
- **About:** Same as "Tell Me About Yourself" — 3–5 sentences
- **Experience:** Mirror your resume bullets
- **Skills:** Top 15 relevant skills; get endorsements from peers
- **Featured:** Pin your best project (GitHub + video demo)
- **Activity:** Post 1-2 technical learnings per week (increases visibility)
- **Connections:** 500+ connections helps SEO; connect with recruiters

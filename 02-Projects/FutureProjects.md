## Criteria for Picking a Project

1. Can I explain it confidently in an interview?
2. Does it solve a real problem?
3. Does it demonstrate a skill I want to highlight?
4. Can I build an MVP in 1–2 weeks?

---

## How to Document a Project

When starting a new project, create a `ProjectName.md` in this folder with:
- What it does (2–3 lines)
- Tech stack
- Architecture / how it works
- Challenges faced
- What I learned
- Potential interview questions about it

- **Core CS** — DBMS, OOP, OS, Computer Networks
- **Projects** — deep dives into what I built and why
- **AI Engineering** — LLMs, RAG, embeddings, agents
- **Interview Prep** — behavioural questions, project walkthroughs
- **System Design** — fundamentals and case studies

## How I use this

- Notes go in as I learn, not after
- Each file is a living document, not a finished resource
- I revisit and update rather than writing once and moving on
- Quality over quantity — I'd rather understand 10 problems deeply than skim 100

Understand first. Memorise later. Build on top.
